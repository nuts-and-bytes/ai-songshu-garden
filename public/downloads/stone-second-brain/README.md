# stone 第二大脑起步包 v2

本文件夹是搭建工具，不是作者私人知识库。

最快方式：在具备文件与终端操作能力的 AI 工具中打开本文件夹，发送 `docs/给AI的搭建提示词.md` 的内容。AI 应当用现成 brain.py 创建一个新的空库，不从头编造脚本。

不使用 AI 也可以按 [开始使用](docs/开始使用.md) 手动操作。完整规则从 [CLAUDE.md](CLAUDE.md) 进入。

需要 Python 3.11+、PyYAML 6.0.3；在 macOS 做了空库脚本验收（Obsidian 界面验收未完成），Linux 与 Windows 尚未实机验收，相关命令提供参考。阅读和图谱还需要自行安装 Obsidian。模型摘要需要自行配置文件型 AI 工具和账号。

脚本默认离线。它保存来源、查重、生成草稿骨架、在明确确认后登记笔记与双链、更新首页/索引/队列、检查和查询；不自行生成摘要、不自动调用付费模型、不安装插件。

已验收范围见 [验收记录](docs/验收记录.md)，依赖和能力差异见 [规则对照](docs/规则对照.md)。
