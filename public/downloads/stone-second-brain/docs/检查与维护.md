# 检查与维护

命令格式为 python brain.py --vault 目标目录 子命令；选择虚拟环境内的 Python。

- doctor：显示 Python、PyYAML 和包版本；不验证模型账号或 Obsidian 插件。
- check：核对原文哈希、注册映射、正式笔记元数据、引用是否在原文、双链、Wiki 回链、首页/索引/队列和日志链。
- query "主题词"：只读返回可追溯的笔记与来源定位；校验失败就停止，不返回受污染来源。
- compile source_id：只读列出相关原文、Note、Wiki；不自动改写概念页。
- health：只读显示检查与待审阅数量；--write 才生成带时间戳的快照并追加日志。

Sources/index.json 与 docs/log.jsonl 由脚本维护。日志每行包含前缀哈希和自身哈希，可发现部分改写/损坏，不是防伪签名；整条重算、完整截断并不能可靠检测。不得声称具备防攻击审计保证。

首页、Notes/index 与队列只更新 stone:auto:start/end 标记之间的区域。标记之外的人工内容保留；缺标记、已有目标文件或错误路径都会停止。Wiki 只追加本次来源索引，不重写已有定义。

禁止并发写同一库。脚本使用排他锁文件；若进程被强制终止，先备份并确认没有仍在运行的写入，再人工清理遗留 .stone.lock，运行 check 查看不一致。正常异常有回滚，断电不保证跨文件原子事务，因此重要库仍应备份。

检查失败后修复实际问题，不能提高基线或修改脚本假装通过。手工编辑正式笔记后也要 check。check 不判断每段话是否忠于来源，不判断 procedure 是否漏步骤，不证明关联的语义正确。

更新规则只维护对应指南；入口保持目录；更新下载包要同步文章、提示词和验收记录。这个包不直接升级旧库，也不修改原作者知识库。
