# 入库与来源

只处理用户本次指定的材料，先 import 查重。支持 UTF-8 文本（Markdown、RST、TXT、文字转录）；不会把二进制 PDF 或音频误当正文。

完整流程：取得原文 → import（保留原件并登记内容哈希）→ 完整阅读 Raw → 编辑 outputs/drafts → 用户核对并复述 → publish → check → Obsidian 实际点击回查。

稳定 source_id 使用内容 SHA-256；Sources/index.json 保存来源、语言、类型、原文哈希、草稿和正式笔记映射。与作者库偏向平台 ID 的方式不同，这是新库版为离线可复现选择的统一策略。

同内容重复导入直接返回已有记录，不改日志或队列；同 URL 新内容会停止，不暗中覆盖旧原文。不同 URL 的相同正文按同一份内容处理，以首次来源为准，暂不自动维护多 URL 别名。

网页获取失败先说明，不能凭标题生成摘要。PDF 需要先 OCR/提取文本并人工核对页码；音视频需先完成独立转录并保留时间戳。原文与最终转录永远保留；只可在用户授权下清理临时下载媒体。

失败项停留待审阅。不能手工将队列改成已完成来绕过检查。新库不导入作者的历史基线、来源注册表或私人内容。
