# 问答与沉淀

先用 brain.py query "主题词" 找证据定位，再打开返回的 Notes、Wiki、Raw 完整阅读；这是本地关键词检索，不是向量检索或完整问答模型。句子没命中时改用一个主题词；无结果就承认没有证据。

三档：
1. 只答不写：日常默认。已有答案给来源链接，不额外生成文件。
2. outputs/qa：用户要求保存的跨材料综合，包含问题、结论、依据、AI 推断、不确定点和回流判定。快照不继续改写。
3. 沉淀：用户真实提出判断并明确要求写入；保留原话蓝色标记，AI 展开黑色，来源回链。原问答快照保留。

面对用户的一句直觉，既找支持，也找反驳；证据不足就说明，不把所有想法都包装为成立。用户没有说过的观点不得写成“我的理解”。

用户明确使用以下口令即表示对应范围的请求：存＝保存当前问答快照；进＝确认把本人观点写入沉淀；沉＝创建以用户主张为题的空笔记；跳＝不落盘；查＝只查证据。口令不是 shell 命令，不代表批量改写授权。

问答快照模板：问题 / 结论 / 依据（Note 和 source_id）/ 我的推断（AI）/ 不确定的地方 / 回流判定（回流、不回流、再放放）。
