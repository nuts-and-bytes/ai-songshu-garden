# Wiki 与关联

同一实体只建一个页面。公开版使用明确路径 `[[Wiki/概念名]]` 与 `[[Notes/来源-主题]]`，避免同名文件猜测。

publish 的 --wiki 只能来自读者确认的实际关联。脚本创建或追加“来源索引”，不自动产生概念定义。定义与综合采用“一句话定义 → 核心内容 → 相关笔记”，让 AI 完整读关联 Notes 和 Sources 后提出修改，确认后保留原文人工段落再写。

每个综合结论须回链来源 Note。单次表述写明来自哪一篇，不冒充长期立场。保留对比项、限制和相反证据；不要用“才是”“本质是”“唯一”等词放大来源。不得用自己的框架词替换说话人的实际语言。

双链只是连接，不能证明因果。图谱节点数量不是完成标准。没有合适关系的笔记可以暂时不连，不为图谱好看批量建空概念页。
