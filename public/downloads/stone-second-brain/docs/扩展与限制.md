# 扩展与限制

## 已提供
离线文本/转录登记、内容去重、原文保留、草稿骨架、明确确认后入库、双链来源索引、首页/索引/队列更新、引用与完整性检查、关键词取证、影响报告、日志和健康快照。

## 需要读者配置
- AI：自行安装具备文件读写能力的工具并登录；服务方案与费用以厂商为准。脚本不会购买额度、读取密钥或自动上传文件。
- Obsidian：自行安装并打开 init 创建的目录。内置双链、反向链接和关系图谱即可阅读；不要求 Dataview、Claudian 或主题插件。
- 网页/PDF：先取得有权处理的完整文本；登录、付费墙、OCR 需要单独处理。脚本不绕过访问限制。
- 音视频：使用你选择的转录工具生成 UTF-8 文本，保留时间戳、说话人和不确定识别，再按 --type video 或 podcast 导入。人名、否定词和引用要回听。

## 没有冒充实现的部分
自动下载与转录、指定云模型全自动摘要、语义检索、跨笔记自动编译成文章、自动个人沉淀、原库主题和插件外观均不打包为“已复现”。

作者库现有音频指南与脚本参数不一致，且脚本依赖 Apple Silicon/MLX、ffmpeg、curl 和模型下载。为避免给其他系统留下坏入口，这个版本不分发那条旧脚本。音视频目前验收边界是“已有文字转录的后续入库”；端到端下载和转录尚未验收。

正常使用不建立定时任务，不自动扫描整个电脑，不上传作者私人内容。读者若使用云端 AI，应理解所选材料可能被发往模型服务端。
