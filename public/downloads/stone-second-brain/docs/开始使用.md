# 从空库开始

## 1. 准备环境

安装 Python 3.11 或更高版本与 Obsidian。把下载包解压到独立文件夹。进入解压后的 stone-second-brain 工具目录，在终端执行：

macOS / Linux：
```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python brain.py doctor
.venv/bin/python brain.py --vault ../我的第二大脑 init
```

Windows PowerShell（未实机验收）：
```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe brain.py doctor
.venv\Scripts\python.exe brain.py --vault ../我的第二大脑 init
```

安装依赖时需访问 PyPI；后续脚本离线运行。不会安装模型或插件，也不会改全局 Python 环境。不必激活虚拟环境；始终使用上面的解释器路径。

`init` 只接受不存在或完全为空的目录。已存在的知识库会被拒绝，不要删除旧库来绕过限制。下面命令都仍从工具目录执行。

## 2. 打开新库

在 Obsidian 选择“打开文件夹为仓库”，打开刚创建的 `我的第二大脑`，再打开 `000-首页.md`。首页最开始没有材料，属于正常状态。

如果你只把工具目录打开为仓库，不会看到自动生成的笔记首页。请确认打开的是 init 创建的目标目录。

## 3. 导入真实示例

包内 examples/python/floatingpoint.rst 是 Python 3.13.0 官方教程原文快照，附原始许可证；不是作者的私人笔记。

```bash
.venv/bin/python brain.py --vault ../我的第二大脑 import examples/python/floatingpoint.rst --title "Python-浮点数与显示误差" --source "https://docs.python.org/3.13/tutorial/floatingpoint.html" --language en --type article --retention insight
```

Windows 将 `.venv/bin/python` 换成 `.venv\Scripts\python.exe`。运行结果是 JSON，会给出实际 source_id、raw 和 draft 路径。不要照抄别人的哈希文件名。

Sources 保存与输入文件逐字节一致的原件；outputs/drafts 出现含 TODO 的草稿骨架；队列显示待审阅。重复导入同一内容不会新增笔记。相同来源正文变了会停止，保留旧版本，等待你决定版本命名。

## 4. 让 AI 读原文并写草稿

在 AI 工具中打开“我的第二大脑”，发送：

> 先读 CLAUDE.md 和入库、笔记模板指南。按刚才 import 返回的 raw 路径完整读取原文，只编辑对应 draft。保留来源元数据；填写摘要、核心要点、值得深挖，清除 TODO。evidence 至少列出一个 claim 和原文中可逐字找到的 quote。区分来源与推断；不要运行 publish。

必须用本次实际路径替换指令中的指代。普通网页聊天不能自动写文件，可手工把输出保存到 draft。

## 5. 读者确认后正式入库

读者至少核对引用、限制、重要对比与关联理由，并用自己的话复述理解。AI 不得编造这段复述。

然后运行以下格式，替换 draft 路径、概念名和 review 文本：

```text
.venv/bin/python brain.py --vault ../我的第二大脑 publish outputs/drafts/实际哈希.md --wiki "实际相关概念" --approve --review "我核对后真实写下的理解"
```

没有相关概念就省略 --wiki；多个相关概念可以重复提供 --wiki。脚本保留草稿原件，新建正式 Note，在 Wiki 中追加来源索引，并更新首页、Notes/index、队列和日志。Wiki 已有人工定义不改写。

Wiki 的定义、跨文章综合仍由 AI 阅读后提出建议、用户确认后写入；脚本不会靠概念名字编定义。

## 6. 验收

```bash
.venv/bin/python brain.py --vault ../我的第二大脑 check
.venv/bin/python brain.py --vault ../我的第二大脑 query "浮点数"
.venv/bin/python brain.py --vault ../我的第二大脑 health
```

打开 Obsidian 首页 → Note → Wiki → Note → Sources，确认每条链接可跳转；在命令面板打开关系图谱或反向链接。图谱会随真实链接积累，不会一键复制作者已有的内容规模。

完成标准：原文仍在、摘要经审阅、正式笔记可回查、索引与队列已更新、check 返回 PASS。不要把“抓到文章”或“AI 回复了”当作完成。
