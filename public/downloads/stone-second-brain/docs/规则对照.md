# 原库规则覆盖与公开版取舍

核对日期：2026-10-28。阅读范围：原库 CLAUDE.md、AGENTS.md、七份现行任务指南、outputs/README、沉淀/README、运行层 README 和相关运行脚本；没有宣称阅读整个私人知识库的全部笔记。

| 原库能力或规则 | 本包实现 | 边界 |
|---|---|---|
| Sources / Notes+Wiki / 沉淀 / outputs 四层 | 完整保留 | 不复制私人内容 |
| 来源保真、语言、元数据 | 规则+import+check | source_id 统一内容哈希；注册表改为 JSON |
| verbatim / procedure / insight | 模板与规则，verbatim 机械检查 | procedure 的完整性和 insight 的忠实性人工审阅 |
| 蓝色用户原话、黑色 AI 内容 | 规则与草稿边界 | 颜色不能自动证明作者身份 |
| Wiki 保留对比、来源和分歧 | 完整保留写作要求 | 自动部分仅来源索引，定义与综合需确认 |
| 问答三档、单字口令 | 指南保留 | 由 AI 理解，不伪装成终端命令 |
| 注册、查重、双向映射 | brain.py import / publish / check | 相同 URL 新正文拒绝覆盖；多 URL 别名暂不支持 |
| compile / query | 只读影响报告 / 关键词证据定位 | 不是语义检索或 LLM 答案 |
| 棘轮门禁 | 新库严格阻断 | 不携带历史基线，也无提高基线入口 |
| 日志哈希链 | JSONL 前缀和记录哈希 | 不复制历史日志，不是防伪签名 |
| 首页、队列和索引 | 标记区更新 | 不复制原库主题、图像和插件配置 |
| 音视频 | 文字转录可导入 | 原音频脚本未直接分发；端到端转录未验收 |
| 自动化测试 | 包内 tests/test_workflow.py | 临时空目录，不碰真实库 |

这里复现的是工作流程及约束，不是相同知识量、相同主题外观或所有机器的相同模型输出。运行器为本次公开包独立实现，没有把原库脚本的历史兼容分支照搬进来。
