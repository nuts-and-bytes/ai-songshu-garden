基于 Git 的云端代码托管与协作平台，2018 年被微软收购，是全球最大的开源社区。

## 核心功能

- **远端同步**：`clone` 下载仓库，`push` 上传本地提交，`pull` 拉取更新
- **Pull Request (PR)**：提交代码合并请求，触发 code review 后由管理员合并
- **Fork**：将他人仓库完整复制到自己账号，用于个性化修改或发起贡献
- **Issues**：任务/Bug 追踪系统

## 开源贡献流程

1. Fork 目标仓库
2. 在 fork 上开发新功能或修复
3. 发起 Pull Request 到原仓库
4. 经 code review 通过后合并
