> 这是我小红书那篇《我把 Claude Code 调教成了知识库管家》的详细版。小红书放成果，完整过程放这儿。

## 它能做到什么

我只要丢一个播客 / 视频 / 文章链接，说一句 `ingest`，它就**自动**：

1. 下载音频、转录成文字
2. 按我定的模板写一篇结构化笔记（摘要 + 核心要点 + 值得深挖）
3. 识别里面的人物和概念，建成 Wiki 原子卡
4. 用 `[[双链]]` 把它们接进知识图谱
5. 更新目录和操作日志

整个过程我不用动手。攒到现在 70+ 篇笔记、200+ 条链接，没有一篇是我手动整理的。

## 三个零件

1. **Obsidian** —— 本地知识库，笔记都存在自己电脑里。
2. **Claudian 插件** —— 让 Claude Code「住进」Obsidian，能直接读写你的文件。
3. **一份 `CLAUDE.md`** —— 给 AI 的说明书，定义它怎么干活。**这是灵魂。**

前两个是工具，真正决定效果的是第三个。

## 灵魂：CLAUDE.md 怎么写

核心是把你的"规则"写成一份说明书，Claude Code 每次都照着做。骨架长这样：

```markdown
# 知识库说明书

## 目录结构
- Notes/  每条来源一篇笔记
- Wiki/   概念 / 人物原子卡
- index   目录
- log     操作日志（append-only）

## 笔记模板
摘要 + 核心要点 + 值得深挖 + 相关笔记

## 工作流 ingest <链接>
1. 判断类型（视频 / 播客 / 文章）
2. 下载转录
3. 按模板写深度笔记
4. 识别实体 → 新建 / 追加 Wiki 卡
5. 补 [[双链]]，更新 index 和 log

## 铁律
忠于原文：每条核心要点都要能在原文里找到对应的句子，
不许凭"理解了大意"就开始写。
```

> 完整版我还加了「忠于原文」的反幻觉约束、Phase 2 外部资料补充、批量处理队列等。想要我这份完整模板，去小红书找我，评论「AI知识库模板」。

## 门槛（说在前面）

- 需要 **Claude Code**（要订阅），这是核心引擎。
- 转录要配 **yt-dlp + 一个转录 API**（我用 Groq Whisper，有免费额度）。
- 建议先跑通"手动把文字喂给 AI 出笔记"的最小版，再上全自动。

实话说这是进阶玩法，不轻松。但一旦跑通，是真省心。
